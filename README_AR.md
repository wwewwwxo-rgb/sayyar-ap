# SAYYAR — حزمة المصدر للرفع إلى GitHub

هذه حزمة Flutter من 5 ملفات، مبنية على مصدر SAYYAR السابق مع ألوان بنفسجية داكنة واسم التطبيق SAYYAR. ليست APK جاهزاً ولم يتم تأكيد نجاح البناء على جهاز حقيقي.

## الملفات
- `lib/main.dart` — التطبيق والخريطة والبحث وحساب المسار والإرشاد الصوتي.
- `pubspec.yaml` — اعتماديات Flutter.
- `.github/workflows/build-apk.yml` — إنشاء مشروع Android وإضافة الأذونات وبناء APK عبر GitHub Actions.
- `android_notes/AndroidManifest_permissions.txt` — مرجع الأذونات.
- `README_AR.md` — هذه التعليمات.

## الرفع
استخرج الملف المضغوط، ثم ارفع محتوياته الخمسة إلى جذر مستودع `sayyar-app` مع الحفاظ على المسارات كما هي، ووافق على استبدال الملفات القديمة. افتح تبويب **Actions** وشغّل **Build SAYYAR APK** (أو ادفع تغييرات الملفات لتشغيله تلقائياً). عند نجاح التشغيل نزّل ملف `SAYYAR-APK` من صفحة التشغيل.

## ملاحظات مهمة
- هذا مصدر قابل للبناء، وليس نسخة مضمونة أو مختبرة مسبقاً. يجب انتظار نجاح GitHub Actions وتجربة APK على الهاتف.
- الخرائط من OpenStreetMap، والبحث يستخدم Nominatim، وحساب المسار يستخدم خادم Valhalla تجريبياً؛ هذه خدمات عامة وقد تتوقف أو تحدّ الطلبات.
- الإرشاد الصوتي يعتمد على توفر محرك TTS والصوت العربي في الهاتف، كما يعتمد التوجيه على GPS والإنترنت.
- لا تدّعي الحزمة تكافؤاً كاملاً مع Waze أو توفر معلومات المرور الحية.
